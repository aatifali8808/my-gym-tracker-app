# 💪 My Gym Tracker

A modern gym workout and fitness tracking application built with **React + Vite**.

Track your workouts, monitor your progress, save personal records, and stay consistent with your fitness journey.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/aatifali8808/my-gym-tracker-app.git
```

Navigate to project folder:

```bash
cd my-gym-tracker-app
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
