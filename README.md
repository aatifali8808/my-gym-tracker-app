# 💪 My Gym Tracker

A modern gym workout and fitness tracking application built with **React + Vite**.

Track your workouts, monitor your progress, save personal records, and stay consistent with your fitness journey.

## ✨ Features

### 🏋️ Workout Tracking
- Chest & Triceps Workout
- Back & Biceps Workout
- Shoulders & Legs Workout
- Exercise-wise weight tracking
- Sets & reps logging
- Personal Record (PR) tracking

### 📊 Progress Tracking
- Current Weight Tracking
- Goal Weight Tracking
- Weight History
- Progress Charts
- Muscle Gain Monitoring

### 💾 Data Management
- Local Storage Based
- Automatic Save
- Backup Export
- Backup Import
- Workout History

### 📱 Mobile Friendly
- Responsive Design
- Dark Gym Theme UI
- Optimized for Mobile & Desktop
